# Резюме-плейбл

Интерактивное резюме на вакансию **Game Designer — Playables (Intern)** в Playrix.

Смысл простой: на вакансию креативщиков невозможно отправить список достижений —
показывать надо самим. Поэтому здесь всё, что рекрутер обычно читает в тексте,
сделано тремя играми. К каждой механике рядом стоит разбор, почему она
сделана именно так, и ссылка на проект, который за ней стоит.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Разметка. Только контейнеры, весь текст — в `content.js` |
| `styles.css` | Вид. Внизу — `@media print` для экспорта в PDF |
| `content.js` | Весь текст, русский и английский. Правь только его |
| `games.js` | Мини-фреймворк и три механики |
| `main.js` | Язык, карусель, подключение механик, замеры |
| `assets/` | Иконка, обложка ссылки, резюме в PDF |
| `tools/make-og.py` | Генератор обложки. Запуск: `python tools/make-og.py` |

## Три механики

1. **Сетка со слиянием.** Уровню отвечают и цвет, и форма — правило читается
   без единого слова. Неудачный ход откатывается сам: промах не наказан.
2. **Попадание по времени.** Пять раундов, зона сужается, темп растёт. Промах
   обнуляет серию, но не отнимает очки — иначе игрок закрывает креатив после
   первой ошибки.
3. **Порядок действий.** Двенадцать кирпичей, очередь считывается с них самих.
   Ошибка — вздрог, а не «начни заново».

## Как это сделано

- **Ноль зависимостей.** Ни фреймворков, ни сборки, ни единого CDN: у рекрутера
  не должен отваливаться интернет посреди просмотра.
- **Открывается двойным кликом** с диска и с любого статик-хостинга.
- **Игра не играет сама.** Никакой автоигры и показа чужой партии: если механика
  цепляет, рекрутер должен убедиться в этом сам, а не смотреть демо. На первом
  экране движение даёт каскад падения фигур, дальше — только то, что сделал
  игрок.
- **Один RAF-цикл на сцену**, пауза вне экрана через `IntersectionObserver`,
  канвас учитывает `devicePixelRatio`.
- **Текста на канвасе нет.** Только игра; все подписи — HTML рядом. Поэтому
  переключение языка ничего не ломает.
- **Уважение к `prefers-reduced-motion`** и к клавиатуре: стрелки двигают фигуру,
  пробел и Enter жмут.

## Что делать, если захочется поменять

| Хочу | Файл |
|---|---|
| Другой текст | `content.js` |
| Другие цвета | переменные в начале `styles.css`, палитра камней — в `games.js` |
| Другие механики | новая функция в `games.js` + регистрация в `REGISTRY` |
| Свой обложка ссылки | `python tools/make-og.py` |

Числа «размер сборки» и «до первого кадра» на странице настоящие: размер
складывается из файлов, время меряется до отрисовки первого кадра. На
`file://` браузер не даёт прочитать файлы — там подставляется запасное число,
вписанное в `main.js`.

## Печать

`Ctrl+P` — печатается документная часть, без креатива, в одну страницу A4.
Это ровно то, что нужно приложить к отклику: PDF читает ATS, интерактив —
это то, ради чего открывают ссылку.
